# Getting started

Welcome. This guide helps you set up your first workspace and invite your team.
Read it from top to bottom the first time. Later, use the headings to find one topic.

## Create your workspace

A workspace holds all your projects, your team, and your settings. When you sign up,
we create one workspace for you. You can give it a name and a logo on the Workspace page.
Most teams use one workspace for the whole company. Some agencies use one workspace for
each client, so that clients never see the projects of other clients.

## Projects and tasks

A project is a list of tasks with one goal, for example "Website launch" or "Hiring Q4".
Each task has a title, an owner, a due date, and a status. You can add comments and files
to a task. You can also split a large task into subtasks. A subtask has its own owner and
due date, but it always belongs to one parent task.

You can see a project as a list, as a board with columns, or as a timeline. The data is
the same in each view. Only the layout changes. Each person can pick their own default
view, and the choice does not change the view for other people.

## Invite your team

Team admins can add or remove users on the Team page. To invite a person, enter their
email address and select a role. There are three roles. A member can create and edit
projects. A guest can see and comment on the projects that you share with them, but they
cannot create projects. An admin can do everything that a member can do, and can also
manage users, billing, and security settings.

Invitations are valid for 7 days. If a person does not accept the invitation in that time,
send a new one from the Team page.

## Keyboard shortcuts

Press the question mark key to see all shortcuts. The most useful shortcut is N, which
creates a new task in the current project. Press slash to search in all your projects.
